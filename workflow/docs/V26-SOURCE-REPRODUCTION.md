## Required inputs and configurations

- **Whole-reference auditor:** requires the original controller/definition, 64 shard receipts and VCFs, final VCFs/indexes/gather lists, reference index and runtime. These case files are absent. Its constants select an exact run/sample and input hashes; they are not exported variant records.
- **Public 84-gene target:** includes both the qualified draft and separately approved public-only configuration. The four public resource files, native runtime, old depth source layout and original qualification are required. Historical target status/design/summary/BED/launch products are absent.
- **84-gene depth:** includes proposed-v2 and approved-v2 configurations because the launcher checks their allowed authorization delta. Both contain the exact inner producer configuration. The CRAM/index, reference/GFF, gene-panel resource, completed-caller metadata, and exact public target products/receipts remain separate. The independent checker additionally needs completed producer outputs and a caller-supplied launch-status hash. Depth is aligned-read evidence, not proof of locus origin, genotype or clinical callability.
- **Public nuclear transform:** includes the approval configuration and pinned plan. Public reference/panel resources, native runtimes and original caller-preservation metadata are separate. Neither the derived panel nor its source-ordinal ledger is exported.
- **Nuclear fictional pilot:** includes qualified sources, receipt and approved plan. Generated fictional alignments/tables are omitted and require a new permitted output to regenerate. These controls do not establish donor-mixture sensitivity.
- **Nuclear assay:** includes proposed-v2 and approved-v2 configurations, all eight source/fixture/qualifier/test files, public versioned source excerpts and the 34-control receipt. Actual CRAM/index/reference, derived public panel/index and caller metadata remain necessary. The older proposal-v1 is informational configuration metadata, not read by execution gates, and is omitted. Patient pileups, model outputs and audit receipts are absent. Finite boundary zero cannot establish sample purity or absence of mixture; the saved-output checker is not an independent read counter or estimator.
- **Population inspection:** includes both configuration versions, Java/Python sources, original Java self-test receipt and runtime identity manifest. `queries.tsv` and `selected-keys.json` are omitted; the latter contains saved prior case-selected resource responses. Even the historical Python `--qualify` wrapper reads those files before starting Java, so it cannot run from this source export alone. The Java source's `--self-test` mode needs only its recorded Java/classpath dependencies and does not open the database. No database or 25-key responses are included.
