Fixed assumptions and interpretation limits

Every displayed scenario begins with 4,000 cells: 20% chromosome-abnormal and 25% senescent. The renewing scenario starts with 800 progenitors; the nonrenewing scenario starts with none. Initial senescence, senescence-associated impairment (1), senescent function (0.25), abnormal-cell function (0.5), crowding capacity (2,000), senescent niche weight (0), and the off-target fraction (0.02) stay fixed in this explorer.

State changes describe aggregate progenitor, differentiated and senescent populations. Individual pedigrees, chromosome-specific changes, tumors, systemic pharmacology and muscle mechanics are outside the model. A higher chromosome-normal fraction can result from differential loss or growth. It does not establish correction of existing cells.

The baseline model and stored intervention effects are fully defined in population.py. The full grid and limitations are in the model documentation. No named drug is assigned to an intervention arm.

Reproduce this view and inspect provenance

From the repository root, run python3 workflow/track2-model/explorer/build_data.py to regenerate the portable data from the retained results. Open this page directly afterward; no server or installation is required to use it.

The export includes both complete result rows, all chosen and fixed assumptions, and source hashes. Numerical checks in the source establish computational consistency, not biological validation.
