# Source evidence and review-depth register

This register preserves the evidence trail for the older **309-appraisal snapshot**, including complete decision objects, original labels, reported reading scopes and all identified gaps. The current ledger contains **310 appraisals**; the [dated addendum](current-ledger-addenda.json) links the newer Risulose preparation review while keeping the original snapshot unchanged.

The historical snapshot contains **874 source-URL occurrences and 8,740 component rows** across abstract, main, native pages/tables/figures, supplement, protocol/SAP, registry/history and notice components. These are source occurrences and review records, not independent drugs, trials or scientific reads. It retains 947 explicitly linked document copies, 14,673 reported depth fields, 1,674 preparation/contrast fields and 12,660 uncapped gap objects. Each count is bound in the [snapshot manifest](snapshot-manifest.json).

The [complete snapshot archive](stage-register-snapshot.tar.gz) contains all 1,008 bound files plus the original final manifest and verification. Every one of its 1,010 members was replayed against original bytes. This preserves all three tabular views, the full JSON register, every verbatim scope/label/preparation field, linked metadata copies, original helper failures and all gaps. It adds no scientific reading or efficacy credit. Internal absolute paths and timestamps describe the original environment; copying a receipt does not reproduce past human reading.

To inspect it locally, extract into a new directory:

```sh
mkdir stage-register-inspection
tar -xzf stage-register-snapshot.tar.gz -C stage-register-inspection
```

Read `stage-register-inspection/stage-register-snapshot/report.md` and `source-evidence-stage-register.json` for the full records. The original `REPRODUCIBILITY.md` explains the frozen-input checks and their limits; execution may require the captured original paths. The snapshot is complete as a file copy, not as a worldwide efficacy assessment.
